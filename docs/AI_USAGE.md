# AI Usage Disclosure — YottaFlex Inventory Intelligence

## AI Tool Used
ChatGPT (OpenAI) was used throughout development.

## How AI Helped
- Breaking the challenge into implementation steps.
- Designing synthetic data, forecasting, and replenishment workflows.
- Generating and refining Python code.
- Troubleshooting errors and dependencies.
- Developing the Streamlit dashboard and FastAPI endpoints.
- Writing tests and technical documentation.
- Troubleshooting Docker and GitHub setup.

## Areas of Heavy AI Reliance
I relied substantially on ChatGPT for implementation guidance,
code suggestions, debugging, and documentation drafts.

## Human Review and Validation
During development, I performed the following checks locally:
- Ran 27 automated tests successfully.
- Verified Python compilation.
- Ran the Streamlit dashboard.
- Exercised the FastAPI application.
- Built and started the Docker application.
- Reviewed forecast and replenishment outputs.

## Limitations
- The project uses synthetic rather than real retailer data.
- Forecasting performance has not been validated on production data.
- Replenishment recommendations require business review.
- The application is a proof of concept, not a production system.
